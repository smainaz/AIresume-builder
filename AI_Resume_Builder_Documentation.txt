Project Overview

The AI Resume Builder is a full-stack web application that enables users to create professional resumes with the assistance of artificial intelligence. The application provides multiple resume templates, real-time preview functionality, and AI-powered content enhancement to help users create compelling resumes quickly and efficiently.

Key Highlights
- Modern React Frontend with Material-UI components
- Node.js/Express Backend with AI integration
- Multiple Resume Templates (Classic, Modern, Minimal, Creative)
- AI-Powered Content Enhancement using OpenRouter API
- PDF Export Functionality with template-specific styling
- User Authentication system
- Responsive Design for all devices

Architecture

Frontend (React)
- Framework: React 18.2.0
- UI Library: Material-UI (MUI) v7.1.2
- Routing: React Router DOM v6.23.0
- PDF Generation: jsPDF v2.5.1
- HTTP Client: Axios v1.6.7

Backend (Node.js)
- Runtime: Node.js with ES modules
- Framework: Express.js v4.18.2
- AI Integration: OpenRouter API (GPT-3.5-turbo)
- CORS: Enabled for cross-origin requests
- Environment: dotenv for configuration

Installation & Setup

Prerequisites
- Node.js (v16+ recommended)
- npm or yarn package manager
- OpenAI API key (for AI features)

Step 1: Clone the Repository
`bash
git clone <repository-url>
cd resumebuilder
`

Step 2: Install Dependencies
`bash
Install all dependencies (root, client, and server)
npm run install:all

Or install individually
cd client && npm install
cd ../server && npm install
`

Step 3: Environment Configuration
Create a .env file in the server directory:
`env
OPENROUTER_API_KEY=your_openrouter_api_key_here
`

Step 4: Start the Application
`bash
Start both client and server
npm run start:client  # Terminal 1
npm run start:server  # Terminal 2

Or start individually
cd client && npm start    # Frontend on http://localhost:3000
cd server && npm start    # Backend on http://localhost:5000
`

Step 5: Access the Application
- Open your browser and navigate to http://localhost:3000
- The application should be running with full functionality

API Documentation

Base URL
`
http://localhost:5000
`

Endpoints

POST /api/ai-resume
Enhances resume content using AI.

Request Body:
`json
{
  "name": "string",
  "email": "string", 
  "phone": "string",
  "summary": "string",
  "experience": "string",
  "education": "string",
  "skills": ["string"] | "string",
  "hobbies": "string",
  "languages": "string",
  "certifications": "string"
}
`

Response:
`json
{
  "name": "string",
  "email": "string",
  "phone": "string", 
  "summary": "AI-enhanced summary",
  "experience": "string",
  "education": "string",
  "skills": ["string"],
  "hobbies": "string",
  "languages": "string",
  "certifications": "string",
  "note": "string (optional)"
}
`

Error Responses:
- 413: Request too large
- 429: Too many requests
- 500: AI service unavailable
- ECONNREFUSED: Server not running

Troubleshooting

Common Issues

1. AI Enhancement Not Working
Problem: "AI enhancement failed" error
Solutions:
- Check OpenRouter API key in server/.env
- Verify server is running on port 5000
- Check API key validity and credits
- Restart the server after adding API key

2. PDF Download Issues
Problem: PDF not generating or missing content
Solutions:
- Ensure resume form is filled completely
- Check browser console for errors
- Verify jsPDF library is loaded
- Try different browser

3. Template Not Loading
Problem: Template preview not showing
Solutions:
- Check if template images exist in public/images/templates/
- Verify template selection in localStorage
- Clear browser cache and reload

4. Authentication Issues
Problem: Login/signup not working
Solutions:
- Check localStorage is enabled
- Clear browser data and try again
- Verify form validation requirements

Debug Mode
Enable debug logging by adding to server/index.js:
`javascript
console.log('Debug: Request body:', req.body);
console.log('Debug: API response:', response.data);
``
